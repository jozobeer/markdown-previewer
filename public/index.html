Markdown
プレビュー

使い方

  1. 左ペインのテキストエリアに Markdown を入力する
  2. 右ペインに見出し・リスト・太字・リンク・コードブロックなどのプレビューが即座に表示される
  3. 入力内容は自動でローカルストレージに保存され、ページを再度開いても復元される

FAQ

入力した Markdown はサーバーに送られますか？
いいえ。ブラウザ内だけで変換・表示し、外部へ送信しません。
ページを閉じても内容は残りますか？
はい。同じブラウザのローカルストレージに自動保存され、次回開いたときに復元されます。
どの Markdown 記法に対応していますか？
見出し、箇条書き・番号付きリスト、太字・斜体、リンク、インラインコード、コードブロック、引用、水平線に対応しています。
